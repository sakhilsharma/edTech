# 📚 EdTech Platform

An **EdTech platform** that offers **placement courses** with recorded lectures, collaborating with colleges and companies to provide students with job opportunities. If a student doesn't get placed, their initial deposit is refunded.

## 🌟 Features
- 🏫 **College Partnerships** to onboard students
- 📄 **Placement Tests** to qualify students for jobs
- 🏢 **Company Collaborations** for job placements
- 📊 **Student Performance Tracking**
- 💰 **Refund System** if no placement is achieved

---

## 🚀 Tech Stack
### **Frontend**
- React + JavaScript
- Vite (for fast development)
- Tailwind CSS (for styling)

### **Backend**
- Node.js + Express.js
- Clerk Authentication

### **Database**
- MongoDB (to store student & course data)

## 🔧 Installation & Setup
### **1️⃣ Clone the Repository**
```sh
git clone https://github.com/your-username/edtech-platform.git
cd edtech-platform
```

### **2️⃣ Install Dependencies**
#### **Frontend:**
```sh
cd frontend
npm install
```
#### **Backend:**
```sh
cd backend
npm install
```

### **4️⃣ Run the Application**
#### **Start Backend**
```sh
cd backend
npm start
```
#### **Start Frontend**
```sh
cd frontend
npm run dev
```
The app should now be running at `http://localhost:5173` 🎉

## 📌 API Endpoints (Backend)
| Method | Endpoint | Description |
|--------|------------|-------------|
| POST | `/auth/login` | User login |
| GET | `/courses` | Get all available courses |
| POST | `/addstudent` | Add multiple students (bulk upload) |
| GET | `/placements` | Fetch placement details |
